# toolchains

## nvm

install latest LTS NodeJS

```bash
nvm install --lts
nvm use node --lts

nvm --version
node -v
npm -v
```

## rustup

install latest stable rust+cargo

```bash
rustup default stable

rustc -V
cargo -V
rustup show
```

## SDKMAN

look at available java

```bash
sdk list java
```

```bash
sdk install java [version]-[distro]
```
also you can install languages, build systems, frameworks

- kotlin
- scala
- gradle
- maven
