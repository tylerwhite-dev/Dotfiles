# Fonts on Windows

- [Nerd Fonts catalog](https://www.nerdfonts.com/font-downloads) — fonts with additional icons for the terminal.
- [Nerd Fonts releases](https://github.com/ryanoasis/nerd-fonts/releases/latest) — font archives.

---

- **Nerd Font:** wider icons, suitable for most terminals.
- **Nerd Font Mono:** fixed-width icons for terminals that require monospaced fonts.
- **Nerd Font Propo:** proportional spacing for graphical interfaces and documents.

## Installation

1. Download the font archive and extract it.
2. Right-click the desired `.ttf` or `.otf` files and select **Install** .
3. Restart the application if the font does not appear.
