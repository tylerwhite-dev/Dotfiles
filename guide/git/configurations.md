## basic setup

### name
```bash
git config --global user.name ""
```

### email
```bash
git config --global user.email ""
```

## save passwords in git
```bash
git config --global credential.helper store
```

## git-lfs
install git-lfs & go to repository
```bash
git lfs install
git lfs fetch
git lfs checkout
```

## git submodule
```bash
git submodule init
git submodule update
```
